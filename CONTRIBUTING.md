# Contributing

Thanks for improving these learning projects.

## Before You Start

1. Read the repository README and existing issues.
2. Open an issue before large changes so the goal is clear.
3. Never include passwords, tokens, private keys, or personal network details.

## Pull Requests

1. Fork the repository and create a focused branch.
2. Make a small, testable change.
3. Update documentation when behavior or lab steps change.
4. Open a pull request using the template and link the related issue.

## Commit Messages

Use a short imperative summary:

```text
docs: add VLAN troubleshooting checklist
feat: add DNS lookup command
fix: handle timeout in port scanner
test: cover invalid IP input
```

Keep every commit meaningful. Do not create empty or repeated commits just to increase activity.
